# Кіннопис

Статичний багатосторінковий сайт про коней, готовий до GitHub Pages і Vercel.

## Каталог порід

- 398 порід і популяцій;
- 14 фізичних HTML-сторінок: `breeds.html`, `breeds-2.html` … `breeds-14.html`;
- по 30 карток на сторінці;
- пошук по всій базі, фільтри, сортування та пагінація;
- докладна інформація відкривається в модальному вікні;
- модальне вікно закривається тільки кнопкою ×;
- для більшості порід використано стилізовані заглушки;
- для популярних та українських порід додано локальні оптимізовані WebP-фотографії.

Дані зберігаються у:

- `data/breeds.json`
- `data/coats.json`

Логіка каталогу:

- `js/breeds.js`
- `js/coats.js`

## Масті

Усі 57 мастей, відтінків і патернів розміщено на одній сторінці `coats.html`, згруповано за типом і доповнено пошуком.

## Локальний запуск

Через обмеження браузерів JSON може не завантажуватися при відкритті HTML подвійним кліком. Запускайте сайт через локальний сервер:

```bash
python -m http.server 8000
```

Після цього відкрийте:

```text
http://localhost:8000/
```

## Фотографії

Відомості про авторів, ліцензії та оригінальні файли Wikimedia Commons наведено:

- у модальних вікнах відповідних порід;
- на сторінці `sources.html`.
